# 🏥 Patient Management System

## 📌 Project Description

The **Patient Management System** is a web-based application developed using ASP.NET MVC. It is designed to efficiently manage patient records, including their personal information, assigned rooms, and medical conditions. The system supports basic CRUD (Create, Read, Update, Delete) operations to ensure organized and accessible data management.

---

## 🛠️ Technologies Used

* ASP.NET MVC
* C#
* HTML
* CSS
* JavaScript
* Bootstrap
* Entity Framework
* SQL Server

---

## ✨ Features

* Add new patient records
* View patient details
* Update patient information
* Delete patient records
* Manage patient rooms
* Manage medical conditions
* User authentication system (if included in your project)

## 🚀 How to Run the Project

1. Clone the repository:

   ```
   git clone https://github.com/lawi107/patient-management-system.git
   ```

2. Open the project in **Visual Studio**

3. Restore NuGet packages if needed

4. Update database connection string (if required)
